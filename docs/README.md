# Ground State — documents

What is written down here is current. Anything that stops being true is changed or removed,
not left as history: the git log is the history.

| file | what it holds | changes when |
|---|---|---|
| [concept.md](concept.md) | what the game is, why it is worth standing in, what it does today | the idea moves |
| [entities.md](entities.md) | every thing a chain has, how the world draws it, and what it would take to draw the rest | a new kind of thing gets a shape |
| [roadmap.md](roadmap.md) | what was built inside ETHOnline 2026, what comes after, in what order | scope moves |
| [deployments.md](deployments.md) | addresses, versions, what is verified where | anything is deployed |
| [operations.md](operations.md) | how to build, test, deploy the site, the live server, the subgraph | the recipe changes |
| [decisions.md](decisions.md) | what was decided and why, what was refused and why | a decision is made |

Not here on purpose: the key to the runes cut into the stones (players are meant to work it out),
private keys, server credentials, and the owner's working notes — those live outside this
repository.

The code carries its own explanation at the top of every file; these documents are for what no
single file can say.
